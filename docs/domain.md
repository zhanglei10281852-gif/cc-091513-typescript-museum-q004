# 领域说明

科学演示开场前需要核对脚本、设备、讲师、耗材、容量和应急人员。检查时间、资质有效期、场次开始时间与事故停用时间共同决定是否可以放行。

`reference/domain.json` 保存公开的场次状态、检查项目和耗材事件枚举。正式业务记录应使用稳定标识，并保留脚本版本、检查证据和例外决定。

## 实现约定

- 场次状态机：`preparing → blocked / ready → running → completed`，事故或人工停用进入 `stopped`，确认事故后可恢复重新评估。
- 六个强制项中 `script`（演示脚本版本）不可例外；其余五个检查项可由具备相应权限的复核者针对当前场次签发例外。
- 设备点检以实际检查时间（`checkedAt`）归属，登记时间（`recordedAt`）仅用于审计；有效窗口见 `src/policy.ts`。
- 耗材事件流：`received → reserved → consumed`，`quarantined` 使批次预留失效；扫码码为幂等键，重复扫码不重复消耗。
- 事故登记时保全快照（场次、闸门评估、点检、耗材事件、例外），并停止同场地后续场次；未确认事故阻止恢复。
- 所有状态持久化于 `.runtime/state.json`，倒计时、停用状态、未确认事故在进程重启后按原时点推进。
